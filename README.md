# Kikuyu-to-English Translation Project

## Project Description
Development and evaluation of an AI-based
Kikuyu-to-English machine translation system.

## Base Model
NLLB-200 Distilled 600M

## Source Language
Kikuyu (kik_Latn)

## Target Language
English (eng_Latn)

## Project Tools
Python, VS Code, Hugging Face Transformers.
